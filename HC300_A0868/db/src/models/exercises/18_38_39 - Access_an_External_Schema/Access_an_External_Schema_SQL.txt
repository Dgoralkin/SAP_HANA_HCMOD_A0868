Task 1:
- To access data outside of your HDI container, you need a user provided service that will connect to the external database.

- This user provided service created and called:  EXT_SCHEMA_SERVICE
- It uses a technical user that has privileges

==============================================================================
CREATE ROLE "externalaccess_roleforOO";
CREATE ROLE "externalaccess_roleforAP";

GRANT SELECT ON SCHEMA TRAINING TO "externalaccess_roleforOO" WITH GRANT OPTION;
GRANT SELECT ON SCHEMA TRAINING TO "externalaccess_roleforAP";

CREATE USER UPS_GRANTOR PASSWORD "Password1" NO FORCE_FIRST_PASSWORD_CHANGE;

GRANT "externalaccess_roleforOO" TO UPS_GRANTOR WITH ADMIN OPTION;
GRANT "externalaccess_roleforAP" TO UPS_GRANTOR WITH ADMIN OPTION;
==============================================================================

* you will need to transfer those rights to the:
	a. Object Owner and 
	b. Application User in your project.

Task 2:
- You must configure synonyms and authorization in order to access the data from any schema outside of your container.

1. In the desired folder (as Synonym), define the .namespace file:
	// Synonyms are created without a namespace
	{
    		"name": "",
    		"subfolder": "ignore"
	}

2. Define the authorizations in a .hdbgrants you want to grant to both the 
	a. object owner
	b. application user on objects.
in Global Roles -> Roles with Admin Option
{
    "user provided service name":{
        "object_owner": {
            "global_roles": [
                {
                    "roles_with_admin_option":["EXT_SCHEMA_ACCESS_OBJOWNER"]
                }
            ]
        },
        "application_user": {
            "global_roles": [
                {
                    "roles":["EXT_SCHEMA_ACCESS_OBJOWNER"]
                }
            ]
        }
    }
}

		!!! Deploy the entire synonyms folder or file only !!!

3. Add the [Schema_Name].hdbsynonym file and define access to schemas and tables.
a. 	In your db → src → synonym folder, create a design-time 	TRAINING.hdbsynonym file that will store synonyms for tables located 	in the TRAINING schema
b. 	Add a synonym for the table ORDERS in the TRAINING schema with the 	following properties:
	Synonym Name	DG::ORDERS
	Object Name	ORDERS
	Schema Name	TRAINING

*In the Find Data Sources dialog box, select the service EXT_SCHEMA_SERVICE.
		!!! Deploy the entire synonyms folder or file only !!!
